# UniManager-PHP
### University Management System with RBAC

A robust web application designed for university administration, featuring Role-Based Access Control (RBAC) for Students and Teachers.

## 🚀 Features
- **Role-Based Access:** Distinct interfaces and permissions for Students and Professors.
- **Course Management:** Create, view, and manage academic courses.
- **Interactive Mapping:** Campus locations visualized using Leaflet.js.
- **Assignment System:** Posting and tracking of student assignments.
- **Grade Synchronization:** Seamless management of student results.

## 🛠️ Tech Stack
- **Backend:** PHP
- **Database:** MySQL
- **Frontend:** HTML5, CSS3, JavaScript
- **Libraries:** Leaflet.js (Mapping)
- **Server:** XAMPP / Apache

## 🔧 Installation
1. Clone the repository to your `htdocs` folder.
2. Import the `sql/database.sql` file into phpMyAdmin.
3. Configure your database connection in `includes/db.php` (or your relevant config file).
4. Access the project via `localhost/prototype`.
